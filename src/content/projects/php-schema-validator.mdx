## Overview

This architecture blueprint explores a clean, dependency-free validation layer for PHP 8.4+ applications—prioritizing readable schema declarations, deterministic error formatting, and strict static analysis compatibility.

## Target Usage Design

```php title="examples/validate-payload.php"
<?php

declare(strict_types=1);

$rules = [
    'title' => ['required', 'string', 'max:140'],
    'published' => ['boolean'],
];
```

## Engineering Scope

Key focus areas include avoiding reflection overhead on hot validation paths, separating scalar coercion from strict constraint checking, and producing predictable JSON-friendly error structures.
