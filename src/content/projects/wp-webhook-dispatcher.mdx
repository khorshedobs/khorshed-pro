## Overview

Modern WordPress and WooCommerce integrations frequently notify external billing, fulfillment, or analytics services. Performing those requests inline during action hooks creates latency spikes and silent data loss during remote outages.

## Outbound Payload Contract

```json title="schemas/webhook-payload.json"
{
  "event": "order.status_updated",
  "timestamp": "2026-03-01T12:00:00Z",
  "delivery_id": "wh_sample_01"
}
```

## Reliability Model

Each event records an immutable delivery envelope, delegates HTTP transport to an asynchronous runner, and signs both the timestamp and serialized payload to protect downstream endpoints against replay attacks.
